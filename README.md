# VehicleRentalManagementSystem
A simple console-based Java application built to manage a vehicle rental fleet.

Java Concepts Used

Core OOP (Inheritance, Abstraction, Encapsulation).
Custom Exceptions to prevent users from renting unavailable vehicles.
Data Structures (Enums, ArrayLists, Inner Classes).
Recursive Methods for discount math.

How to Use
Download the src folder.
Open the project in Eclipse IDE or VS Code.
Run Main.java and type numbers in the console to navigate the interactive menu.
